# Instant Weight-Space Consolidation for Long-Term Memory in LLMs

Project page for **CLAM** (Carried Latent Adapter Memory).

Manan Suri, Dinesh Manocha — University of Maryland, College Park

Live at <https://complementary-memory.github.io>.

## Layout

```
index.html              the page
static/css/style.css    styles
static/js/main.js       KaTeX rendering, table overflow hints, copy-to-clipboard
static/images/          figures and tables cropped from the paper
```

Static HTML — no build step. To preview locally:

```bash
python3 -m http.server 4319
```
